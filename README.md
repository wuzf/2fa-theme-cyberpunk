# Neon Vault · 霓虹密库

这是 [wuzf/2fa](https://github.com/wuzf/2fa) 项目的主题，不能单独运行：需要先部署 2FA（2.0.0 或更高版本），再在 **设置 → 外观与主题 → 主题 → 社区主题** 中安装。

一款赛博朋克风格的 2FA 主题：深海军蓝底色、荧光黄操作按钮、青色验证码，以及 HUD 布局：顶栏中央的倒计时反应堆、左侧发光的服务导轨和错落排布的切角保险库面板。支持浅色、深色和手机布局。

版本 **1.0.0**，主题 ID **`cyberpunk-for-2fa`**。需要支持 Theme API 2 / SDK API 1 的 2FA 主机。账户、验证码、复制和账户管理继续使用主机 SDK。

## 安装

自己构建时（见下方「本地开发」），在 2FA 中打开 **设置 → 外观与主题 → 导入主题**，选择 `dist/2fa-theme.zip`，预览后点击 **应用外观**。

完整前端主题以同源 JavaScript 运行，请仅应用信任的主题。需要恢复官方界面时，访问实例地址并添加 `?safeMode=1`。

主界面默认使用账户卡片，顶部仅保留“管理”。添加账户位于“管理 → 账户与数据”，空账户库仍有添加引导。排序收在“视图”，明暗切换和其他功能集中在管理页。

## 主题设置

| 设置     | 可选值       | 默认   |
| -------- | ------------ | ------ |
| 信息密度 | 舒适、紧凑   | 舒适   |
| 强调色   | 荧光黄、青色 | 荧光黄 |
| 背景网格 | 开、关       | 开     |
| 霓虹光晕 | 开、关       | 开     |

明暗模式与语言跟随主机偏好；品牌名称、说明和图片使用主机中的个人品牌配置。

## 本地开发

需要 Node.js 20 或更新版本。

```powershell
npm install
npm run build
npm run dev
```

开发预览地址为 `http://127.0.0.1:4217`，构建包输出到 `dist/2fa-theme.zip`。

开发壳使用合成账户和时间；复制使用模拟反馈；点击添加账户、设置等需要真实实例的操作时，弹窗说明此处仅为主题示例，应在安装主题的 2FA 实例中使用。预览不读取真实账户，不收集密钥，也不写入剪贴板或服务器。它用于检查主题界面，不能代替真实主机的安装与业务验收。

运行测试及主机包校验：

```powershell
$env:HOST_ROOT = (Resolve-Path '..\2fa').Path
npm test
npm run test:host
```
