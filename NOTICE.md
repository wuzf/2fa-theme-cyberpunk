Neon Vault is a cyberpunk theme for 2FA Theme API 2 / SDK API 1.

The account, command, navigation, internationalization and lifecycle adapter
is adapted from **Receipt / 2fa-theme-receipt**, which is based on
**Pixel / 2fa-theme-pixel**, copyright (c) 2026 2FA Pixel contributors,
under the MIT License. Their license texts are preserved in
`licenses/Receipt-MIT.txt`, `licenses/Pixel-adapter-MIT.txt` and the root
`LICENSE`.

The cyberpunk layout, palette and CSS effects use no third-party images
or bundled fonts. Typography uses fonts already installed on the user's
device; no font files are redistributed or fetched from a CDN.
